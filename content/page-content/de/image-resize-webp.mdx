WebP ist bereits ein kompaktes Format, aber ein zu großes WebP ist trotzdem verschwendete Bandbreite. Bilder in der Größe auszuliefern, in der sie angezeigt werden, ist eine der einfachsten Methoden, eine Seite zu beschleunigen. Ziehen Sie Ihre WebP-Dateien hinein, legen Sie die Größe fest und erhalten Sie WebP-Dateien, die zu Ihrem Layout passen.

## So ändern Sie die Größe von WebP-Bildern

1. Ziehen Sie Ihre WebP-Dateien in das Feld oben oder klicken Sie, um sie auszuwählen. Sie können beliebig viele hinzufügen.
1. Wählen Sie die neue Größe: einen Prozentsatz des Originals (standardmäßig 50 %), eine genaue Breite oder eine genaue Höhe. Klicken Sie auf Weitere Größen, um mehrere Versionen auf einmal zu erhalten.
1. WebP ist bereits als Ausgabeformat ausgewählt. Öffnen Sie die Erweiterten Einstellungen, um JPG-, AVIF- oder PNG-Kopien hinzuzufügen.
1. Klicken Sie auf Größenänderung starten und laden Sie jede Datei einzeln oder alle auf einmal herunter. Nichts wird hochgeladen: Alles läuft in Ihrem Browser.

## Warum WebP-Bilder verkleinern?

Responsive Bilder funktionieren am besten mit mehreren Breiten jedes Motivs, zum Beispiel 480, 960 und 1600 Pixel, damit Smartphones nie Dateien in Desktop-Größe laden. Mit Weitere Größen erhalten Sie alle in einem Durchgang. JPGs oder PNGs, die Sie hier hinzufügen, werden ebenfalls als WebP ausgegeben: ein schneller Weg, einen Bilderordner zu modernisieren.

## Häufig gestellte Fragen

<FAQ question="Bleibt beim Verkleinern die Transparenz meines WebP erhalten?">
  Ja. Transparente Pixel bleiben im verkleinerten WebP erhalten.
</FAQ>

<FAQ question="Was ist mit animierten WebP-Dateien?">
  Nur der erste Frame wird übernommen, das Ergebnis ist also ein Standbild.
</FAQ>

<FAQ question="Werden meine Bilder hochgeladen?">
  Nein. Alles läuft in Ihrem Browser, auf Ihrem Gerät. Ihre Bilder werden nie
  auf einen Server hochgeladen, daher eignet sich das Tool auch für private und
  vertrauliche Dateien.
</FAQ>
