PNG-Dateien sind verlustfrei und deshalb schwer, wenn sie groß sind. Ein Logo, Icon, Screenshot oder Freisteller auf die tatsächlich angezeigte Größe zu verkleinern, macht die Datei deutlich leichter, und der transparente Hintergrund bleibt genau so, wie er war. Ziehen Sie Ihre PNGs hinein, wählen Sie die Größe und laden Sie die verkleinerten Versionen herunter.

## So ändern Sie die Größe von PNG-Bildern

1. Ziehen Sie Ihre PNG-Dateien in das Feld oben oder klicken Sie, um sie auszuwählen. Sie können beliebig viele hinzufügen.
1. Wählen Sie die neue Größe: einen Prozentsatz des Originals (standardmäßig 50 %), eine genaue Breite oder eine genaue Höhe. Klicken Sie auf Weitere Größen, um mehrere Versionen auf einmal zu erhalten.
1. PNG ist bereits als Ausgabeformat ausgewählt. Öffnen Sie die Erweiterten Einstellungen, wenn Sie auch WebP- oder AVIF-Kopien möchten, die viel leichter sind.
1. Klicken Sie auf Größenänderung starten und laden Sie jede Datei einzeln oder alle auf einmal herunter. Nichts wird hochgeladen: Alles läuft in Ihrem Browser.

## Warum PNG-Bilder verkleinern?

App-Icons, Favicons, Profilbilder und Screenshots für Dokumentationen brauchen exakte Abmessungen. Die Größenänderung im Browser liefert diese Größen in Sekunden, mit weicher, hochwertiger Skalierung und intaktem Alphakanal. Bilder in anderen Formaten, die Sie hier hinzufügen, werden ebenfalls als PNG gespeichert.

## Häufig gestellte Fragen

<FAQ question="Bleibt der transparente Hintergrund erhalten?">
  Ja. Transparente und halbtransparente Pixel bleiben im verkleinerten PNG
  erhalten.
</FAQ>

<FAQ question="Kann ich ein kleines Icon vergrößern?">
  Nein. Das Tool vergrößert nie, weil ein kleines Bild dadurch nur unscharf
  wird. Gehen Sie von der größten Version aus, die Sie haben.
</FAQ>

<FAQ question="Werden meine Bilder hochgeladen?">
  Nein. Alles läuft in Ihrem Browser, auf Ihrem Gerät. Ihre Bilder werden nie
  auf einen Server hochgeladen, daher eignet sich das Tool auch für private und
  vertrauliche Dateien.
</FAQ>
