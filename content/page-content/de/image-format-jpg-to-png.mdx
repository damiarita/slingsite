Jedes Mal, wenn Sie ein JPG bearbeiten und speichern, wird es erneut komprimiert und verliert etwas mehr Detail. Wenn Sie es vorher in PNG umwandeln, erhalten Sie eine verlustfreie Arbeitskopie: Sie können sie zuschneiden, beschriften und so oft speichern, wie Sie wollen, ohne neue Artefakte. Das hilft auch, wenn ein Tool oder Formular nur PNG akzeptiert.

## So konvertieren Sie JPG in PNG

1. Ziehen Sie Ihre Bilder in das Feld oben oder klicken Sie, um sie auszuwählen. Sie können beliebig viele hinzufügen.
1. PNG ist bereits als Ausgabeformat ausgewählt. Aktivieren Sie weitere Formate, wenn Sie diese ebenfalls brauchen.
1. Optional: Öffnen Sie die Erweiterten Einstellungen, um nach Prozent, Breite oder Höhe zu skalieren und weitere Größen hinzuzufügen.
1. Klicken Sie auf Konvertierung starten und laden Sie jede Datei einzeln oder alle auf einmal herunter. Nichts wird hochgeladen: Die Konvertierung läuft in Ihrem Browser.

## Warum JPG in PNG konvertieren?

Verwenden Sie PNG für Bilder, die Sie weiter bearbeiten, für versehentlich als JPG gespeicherte Screenshots oder wenn eine App, eine Vorlage oder eine Druckerei PNG verlangt. Rechnen Sie mit größeren Dateien: Ein Foto als PNG ist oft ein Vielfaches des JPG. Zum Veröffentlichen auf einer Website bleiben JPG, WebP oder AVIF die bessere Wahl.

## Häufig gestellte Fragen

<FAQ question="Sieht das PNG besser aus als mein JPG?">
  Es sieht genauso aus. PNG behält die Pixel exakt bei, einschließlich der
  Kompressionsartefakte, die das JPG bereits hat, und verhindert neue.
</FAQ>

<FAQ question="Bekommt das PNG einen transparenten Hintergrund?">
  Nein. Ein JPG hat keine Transparenz, daher behält das PNG denselben
  einfarbigen Hintergrund. Zum Entfernen eines Hintergrunds brauchen Sie ein
  Bildbearbeitungsprogramm.
</FAQ>

<FAQ question="Werden meine Fotos hochgeladen?">
  Nein. Die Konvertierung läuft vollständig in Ihrem Browser, auf Ihrem Gerät.
  Ihre Fotos werden nie auf einen Server hochgeladen, daher eignet sich das Tool
  auch für private und vertrauliche Dateien.
</FAQ>
