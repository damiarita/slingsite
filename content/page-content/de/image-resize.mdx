Bilder direkt aus der Kamera oder vom Smartphone sind oft 4000 Pixel breit oder mehr, viel größer als jeder Bildschirm, jede E-Mail oder Webseite braucht. Sie zu verkleinern ist der schnellste Weg, ihr Gewicht zu reduzieren. Ziehen Sie Ihre Bilder hinein, wählen Sie die neue Größe und laden Sie sie herunter: Jedes behält sein Format und seine Proportionen.

## So ändern Sie die Größe von Bildern

1. Ziehen Sie Ihre Bilder in das Feld oben oder klicken Sie, um sie auszuwählen. Sie können beliebig viele hinzufügen.
1. Wählen Sie die neue Größe: einen Prozentsatz des Originals (standardmäßig 50 %), eine genaue Breite oder eine genaue Höhe. Klicken Sie auf Weitere Größen, um mehrere Versionen auf einmal zu erhalten.
1. Optional: Öffnen Sie die Erweiterten Einstellungen, um das Ausgabeformat zu ändern. Standardmäßig behält jedes Bild sein eigenes Format.
1. Klicken Sie auf Größenänderung starten und laden Sie jede Datei einzeln oder alle auf einmal herunter. Nichts wird hochgeladen: Alles läuft in Ihrem Browser.

## Größe nach Prozent, Breite oder Höhe ändern

Ein Prozentsatz ist ideal für einen gemischten Stapel: Jedes Bild wird um denselben Anteil verkleinert. Eine genaue Breite brauchen Sie für eine Website-Spalte, eine Blog-Vorlage oder einen Marktplatz, der 1200 Pixel Breite verlangt. Eine genaue Höhe passt für Banner und Vorschaubild-Leisten. Die andere Seite wird immer für Sie berechnet, sodass nichts gestreckt oder gestaucht wird.

## Häufig gestellte Fragen

<FAQ question="Kann ich ein Bild vergrößern?">
  Nein. Das Tool vergrößert nie: Wenn Sie eine Größe über dem Original angeben,
  behält das Bild seine Originalgröße. Vergrößern fügt nur Unschärfe hinzu,
  keine Details.
</FAQ>

<FAQ question="In welchem Format erhalte ich die Bilder?">
  Im selben wie das Original: JPG bleibt JPG, PNG bleibt PNG, WebP bleibt WebP
  und AVIF bleibt AVIF. Formate, die wir nicht erzeugen können, wie GIF, werden
  als WebP gespeichert (von einer Animation bleibt nur der erste Frame). In den
  Erweiterten Einstellungen können Sie andere Formate wählen.
</FAQ>

<FAQ question="Werden meine Bilder hochgeladen?">
  Nein. Alles läuft in Ihrem Browser, auf Ihrem Gerät. Ihre Bilder werden nie
  auf einen Server hochgeladen, daher eignet sich das Tool auch für private und
  vertrauliche Dateien.
</FAQ>
